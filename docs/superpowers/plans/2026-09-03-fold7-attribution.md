## 0. 待解释的事实

fold_7 = 滚动重训（训练至 2025-12-31，168 因子）在 2026-01-05~2026-06-30 验证：

| 指标 | 值 |
|---|---|
| 总收益 / 年化 | **-15.5% / -30.6%** |
| 基准年化（CSI1000 口径） | -0.7% |
| 超额年化 | **-29.9pp**（IR -1.01, Sharpe -1.30, MaxDD -21.1%） |
| 调仓 / 成交 | 6 次计划调仓，**22 笔成交，但只发生在 2 个交易日**（2026-01-06 建仓 19 买 + 2026-06-09 换仓 2 买 1 卖） |

**结构事实（本次审查最重要发现）**：6 次调仓里 4 次产生 **0 笔交易**——2026-01-06 一次性建满 19~20 只后，组合在整个 2026H1 处于"静态持仓"状态，直到期末才发生一笔换仓。因此 -15.5% 总收益本质上是一次建仓决策 + 半年价格漂移的结果，不是"半年内连续调仓决策链"的累积。对照 fold_6（2025，30 笔/4 个成交日）与 fold_5（5 个成交日）——低频是本策略常态（低换手配置 hold45/buffer6/n_drop6），但 fold_7 是其中最极端的。

## 1. H1 因子方向反转 —— 不支持“大面积反转”，但存在中等权重暴露

方法：对 fold_7 每期调仓权重的 168 个因子，用验证窗（2026-01-05 起 21 日前瞻收益，逐日截面 Spearman）实测 IC 方向，与 `weights_evolution` 中的下注方向（权重符号）对比。下注方向是训练结果的可观测代理；本脚本没有重新读取训练期逐因子 IC 序列，因此不能把它表述为独立的“训练期 IC vs 验证期 IC”检验。

全市场结果：168 个下注因子中 **98 个可由本地 DSL 面板重算，8 个方向相反**，反向因子占最后一期下注绝对权重 **11.1%**；6 个调仓日的可测方向命中均为 78/86。反向因子包括 `rev_mom_spread`、`sumd_20`、`sumn_20`、`sump_20`、`resi_60`、`sharpe_20d`、`realized_vol_ratio`、`return_90d`，其中部分验证期 IC 幅度很小，不能仅凭符号断言其造成了亏损。

**结论**：不支持“168 个因子整体方向大面积反转”，但 11.1% 的下注权重落在方向不一致因子上，足以保留为候选风险，不能沿用冒烟阶段“仅 0.8% 权重”的旧结论。另有 70 个因子未被本脚本的 `full_auto` DSL 面板重算（包括 `fund_*`、`aux_*`、`ind_mom_60`、分钟因子及部分未进入该 preset 的技术因子），因此 H1 仍不是完整的 168 因子归因。

## 2. H2 regime 误判 —— 证据不足，倾向"不是主因"

方法：回放 `RegimeDetector`（CSI1000 基准）在 116 个交易日的 detect_v2 分类与 `get_weight_multipliers` 乘数，对照当日之后 20 日 CSI1000 实际收益。

| 量 | 值 |
|---|---|
| 分类计数 | RANGE 57 天 / TREND_UP 51 天 / TREND_DOWN 8 天 |
| 风险关闭日（momentum 乘数<1） | 65 天，其后 20 日平均 **-3.28%** |
| 风险开启日（乘数≥1） | 51 天，其后 20 日平均 **-4.52%** |
| 风险关闭但实际 20 日上涨占比 | 26.2% |
| 风险开启但实际 20 日下跌占比 | 72.5% |
| 波动率分位 | <0.30: 25 天 / 0.30~0.70: 75 天 / >0.70: 16 天 |

解读：检测器把 2026H1 大部分日子判为 UP/RANGE（51+57 天）而实际 20 日窗口多为阴跌（风险开启日 72.5% 实际下跌）——存在"把阴跌市当震荡/上涨"的系统性偏差；但风险关闭日并不比风险开启日跌得更多（-3.28% vs -4.52%），说明即便误判，其仓位乘数方向（风险关闭时低配动量类）在下跌环境并未放大亏损。**结论：regime 判断偏差存在但不是亏损放大器；证据不支持它作为主因。**

## 3. H3 持仓过度集中 —— 否（单票/已知行业均未触及约束上限）

方法：按成交日期回放 `trades`，在 `positions_history` 调仓日用收盘价估算相对持仓内部权重（存档无逐日市值，仍是近似口径）。6 个存档调仓日中首日是成交执行前的空仓，因此有 5 个有效持仓快照。

| 量 | 值（6 期均值 / 最大） |
|---|---|
| 持仓数 | 19（5 个有效快照；1 月 5 日成交前为空仓） |
| 单票上限 | **7.2% / 7.6%**（20% 约束远未触及，0/5 期打满） |
| 已知行业最大 | **14.7% / 15.5%**（农林牧渔 15.5% 为最大已知行业；25% 约束 0/5 打满） |
| 行业 map 未覆盖桶 | **30.9% 均值 / 31.6% 最大**（约 6 只无分类，属 map 覆盖缺口，不能据此认定集中） |

组合内部近似等权（每票 ~5%），**单票/行业集中度都不支持 H3**。真正相关的是 §0 的结构事实：静态持仓 + 行业涨跌分化决定全年结果。

## 4. H4 执行侧 —— 暂不支持是主因（但有 1 行数据质量候选）

方法：fold_7 的 22 笔成交价 vs 当日分钟 VWAP（minute_5m）与收盘价；分钟覆盖 22/22。

| 侧 | n | vs 当日 VWAP 均值 / 中位数 | vs 收盘均值 | 备注 |
|---|---|---|---|---|
| BUY | 21 | **-178.8bp / -50.0bp**（中位有利） | -40.7bp | 含 1 行 suspect，原始均值受其影响 |
| SELL | 1 | -86.4bp | - | 期末唯一卖出略低于 VWAP |

- 剔除 suspect 行后 BUY 均值 ≈ **-38.6bp**（有利）。全运行 execution_quality（206 笔）BUY vwap_dev 中位 22.2bp——fold_7 自身残差量级不超全运行水平。
- **数据质量候选**：600508 一笔显示 -2982bp（fill 8.43 vs “VWAP” 12.01）。本地分钟 `amount/volume` 隐含价与日线 OHLC（约 8.46）不一致，比例约 1.42；这只能证明该行不可直接用于执行归因，不能在未重拉/对齐复权口径前断言它一定是伪影。脚本以 `|残差|>500bp` 标记为 suspect，但原始均值仍包含该行。
- **结论**：在剔除该 suspect 行的敏感性计算中 BUY 均值约 -38.6bp，仍未显示执行放大亏损；但在数据治理完成前，H4 的精确残差只能作为方向性证据，600508 不应进入执行质量基准。

## 5. H5 样本量不足 —— 是（点估计信息量很弱）

方法：`daily_active_returns`（116 日，小数单位）均值/标准差 → 年化超额，并给出 t 分布近似的敏感性区间；21 日重叠标签用 `floor(116/21)=5` 做一个保守敏感性折算。该 `neff` 不是经自相关估计得到的正式有效样本量，下面的区间不是可直接用于发布的正式置信区间。

| 量 | 值 |
|---|---|
| 日均超额 / 日波动 | -0.137% / 2.171% |
| 年化超额点估计 | -34.6pp（官方口径 -29.9pp，口径差≈基准/序列对齐） |
| 95% t 分布近似敏感性区间（116 日全样本） | **[-135.3pp, +66.0pp]** |
| 95% t 分布近似敏感性区间（neff=5） | [-714pp, +645pp]（重叠/自相关下仅作宽度示意） |
| 独立决策数 | **1~2 次**（§0：22 笔成交仅 2 个交易日） |

解读：半年 116 日、日均波动 2.17% 的 20 票组合，点估计的敏感性区间横跨 ±100pp；再叠加实际上只有 1~2 个有成交的独立决策日，fold_7 的 -30.6% 更应解读为“一次建仓时点 + 持仓半年的高方差实现值”。它不能证明滚动重训体系已经系统性失效，也不能证明策略有效；只能说明当前样本不足以作强结论。

## 6. 最可能解释排序（供人工决策）

1. **（最强）单次下注的样本噪音 + 静态持仓暴露**：1-2 次独立决策 + 半年无换仓 + 组合内部近似等权 → -15.5% 是一次组合抽样的实现值，CI 与 0 不可区分（H5 + §0）。低频低换手纪律（hold45/buffer6/n_drop6/确认2）在 2026H1 的表现是"买了不动"，本身放大了单次建仓时点的影响——这同时是 fold_7 与 fold_6 的共同模式。
2. **建仓时点/因子权重组合在 2026H1 的负漂移**：全量 H1 不支持大面积方向反转，但 8/98 可测因子反向且占最后一期下注权重 11.1%；IC 幅度、非 DSL 因子和选股组合层面的失效仍未被本诊断识别。
3. **regime 判断系统性偏乐观**（H2）：51 天 UP + 57 天 RANGE vs 实际 20 日窗口 72.5% 下跌，风险关闭机制启动太晚/太少；但未放大亏损。
4. 相对排除：执行（H4，已知可比行的残差总体有利，但 600508 数据待治理）、单票/已知行业集中（H3，未触限）、因子方向“大面积”反转（H1 不支持，但非 DSL 因子未测）。
