# 回测成交价假设的困境 — 问题梳理

> 日期: 2026-08-15
> 状态: 问题与困境梳理（解决方案待定，本文不涉及）
> 相关代码: `data/minute_fetcher.py`（get_pov_fills/get_pov_price）、`model/engine.py`（_exec_price/_pov_price）、`scripts/active/run_walkforward_backtest.py`

## 一、背景：我们在讨论什么

我们的策略是 **月频调仓**（约 20 个交易日调一次仓），信号在 T 日生成，T+1 日执行买卖。回测时，每一笔买入/卖出都需要假设一个**成交价**——但回测是"事后"的，我们不可能真的在当天交易，所以必须选择一个"模拟成交价"。

这个模拟成交价直接决定了回测收益的**真实性**：假设太乐观，回测成绩虚高；假设太保守，好策略被埋没。

我们当前用的执行模型是 **POV（成交量比例拆单）**：大订单按当日每分钟的成交量节奏分批买入（量大的时段多买，量小的时段少买）；而 **小订单（占我们 295/296 笔，<0.1% 日成交量）走简化路径**。

**这正是困境的起点：小订单（几百到几千元）怎么定价？**

---

## 二、问题：四种定价方案，四种困境

我们先后尝试了四种"小订单成交价"假设，每一种都有致命缺陷：

### 方案 1：按当日全天 VWAP 均价成交（旧实现）

**想法**：小订单对市场无冲击，直接按当天所有成交的加权平均价成交，最简单。

**问题**：
- **前视偏差（look-ahead bias）**：全天 VWAP 是**收盘后**才知道的价格。回测里假设"我以全天均价成交"，等于假设我提前知道了全天的成交分布——这在现实中不可能
- 没有人能保证自己拿到全天均价：你下单那一刻的价格，跟全天均价可能有 1%~2% 的偏差
- 回测收益被系统性**高估**：相当于免费获得了完美执行

### 方案 2：固定"早盘市价"成交（第一次修改）

**想法**：既然不能拿全天均价，那就假设调仓日 09:35（开盘后第一根 5 分钟 bar）按当时市价成交——开盘后立即动手，很真实？

**问题**：
- **机械**：为什么一定是 09:35？调仓日当天可能高开 5% 等着回落，也可能低开恐慌正好是机会——**固定时点完全无视日内行情**
- 现实中你不太可能每天都恰好 09:35 下单；有时你早上有事，有时你看到盘面不好想等一等
- 用户评价："这完全就是机械的交易策略"

### 方案 3：随机时点市价成交（第二次修改）

**想法**：既然固定时点机械，那就**随机**选一个时点成交（用固定种子保证可复现），模拟"你也不知道自己几点下单"的不确定性。

**问题**：
- **随机 ≠ 真实**：真实的交易者不是"随机"决定下单时间的——他们会看盘、会判断、会等时机
- 随机定价让单次回测结果带随机性：同一策略跑两次，因为随机种子不同，成绩可能不同（虽然我们用固定种子规避了这一点，但**种子选哪个本身就是任意的**）
- 用户评价："真实的量化模型会进行随机成交吗？"

### 方案 4（隐含的想法）：不做日内定价，按开盘价/收盘价

**想法**：干脆用最朴素的 T+1 开盘价或收盘价。

**问题**：
- 开盘价：同样机械（无视日内行情），且开盘价往往是全天波动最大的时刻（跳空、集合竞价博弈）
- 收盘价：更糟——收盘价是**当日最后一刻**的价格，比全天 VWAP 更"事后"

## 三、困境的本质：三个不可能三角

把上面的问题抽象出来，我们看到三个互相拉扯的要求，**任何单一"固定规则"都无法同时满足**：

```
        真实感（符合实际操作）
              ▲
             / \
            /   \
           /     \
  无前视偏差 ────── 可复现性（回测确定性）
```

1. **无前视偏差**：成交价必须是下单那一刻"已知"的价格，不能用收盘后才知道的信息（全天 VWAP 违反这条）
2. **真实感**：定价方式要像真实的交易者——会看盘、会择时、不是固定时点也不是随机
3. **可复现性**：回测必须确定：同一策略同一参数，跑出来的成绩应该一致（随机定价违反这条）

**固定时点**（方案 2）满足 1 和 3，违反 2——机械。
**随机时点**（方案 3）满足 1，违反 2 和 3——奇怪。
**全天 VWAP**（方案 1）满足 3，违反 1 和 2——虚高。
**开盘价/收盘价**（隐含方案 4）满足 1 和 3，违反 2——同样机械。

## 四、核心疑问：真实的量化是怎么做的？

用户提出的一连串追问，本质是在问一件事：

> **"我们为什么不在日内找一个好的买卖时机？真实的量化不都是观察日内行情、择时交易的吗？"**

这个追问背后，是几个尚未完全澄清的假设：

1. **"日内择时"到底指什么？**
   - 是**预测**日内价格走向（10:00 买比 09:35 买便宜）？——这需要高频/日内预测模型，学术界共识是分钟级价格接近随机游走，预测 alpha 极弱
   - 还是**条件式执行**（看到高开 5% 就等回落再买，看到低开恐慌就立即买）？——这是"用规则过滤极端情况"，不预测价格，只避免最差入场点

2. **月频策略做日内择时有意义吗？**
   - 我们的信号持有 20 天，一天之内的入场时点差异（10:00 vs 14:00）对 20 天收益的影响通常 <0.5%
   - 但 0.5% 不是零——且它直接影响**执行质量**（滑点、冲击、最差入场点）

3. **回测应该模拟"聪明的执行"还是"普通的执行"？**
   - 如果回测假设执行者会看盘择时（聪明），但实盘做不到，回测虚高
   - 如果回测假设执行者完全机械（普通），可能低估真实能力
   - 我们系统里还有一个**模拟盘执行器**（paper_executor），它才是真正逐分钟跑的地方——回测和模拟盘的执行假设应该怎么对齐？

4. **数据支撑够不够？**
   - 我们已有本地 5m 分钟全历史数据（2022 起，5053 只）——日内信息（开盘缺口、量比、前 30 分钟走势）都是可计算的
   - 但回测引擎目前只用了它做"拆单节奏"，没有用它做"择时决策"

## 五、已知事实清单（供后续讨论用）

以下是我们**已经确认的事实**，无论最终方案是什么，这些都不能变：

- [x] 我们 295/296 笔成交是小订单（<0.1% 日成交量），中位金额 ~3000 元
- [x] 全天 VWAP 作为成交价存在前视偏差，会高估回测收益
- [x] 固定时点（09:35）机械，无视日内行情
- [x] 随机时点不真实，且引入回测不确定性（虽然可固定种子规避）
- [x] 月频策略的日内择时收益空间有限（预期 <0.5%/年量级），但真实存在
- [x] 我们已有 2022 年起的 5m 分钟数据，日内信息可计算
- [x] 回测引擎和模拟盘执行器是两个不同的执行路径，需要对齐
