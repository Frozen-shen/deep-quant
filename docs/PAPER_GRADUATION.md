# 模拟盘毕业标准 — Paper → Live Trading

> **核心理念**: 模拟盘是实盘前的最后一道防线。不是跑赢了就能升级，而是要在足够长的时间内、足够稳健地跑赢。

---

## 毕业条件

### 必须全部满足 (AND 关系)

| 条件 | 阈值 | 说明 |
|------|------|------|
| **运行时长** | ≥ 3 个月 | 覆盖至少一个完整财报季，检验因子在不同市场环境下的表现 |
| **年化超额收益** | > 5% (扣成本后) | 超额 = 策略收益 - 基准收益 (沪深300/中证500等权) |
| **信息比率 (IR)** | > 0.5 | IR = 年化超额收益 / 超额波动率，衡量alpha稳定性 |
| **最大回撤** | < 15% | 从模拟盘开始日到当前权益最高点的最大跌幅 |
| **信号实现率 (买入)** | > 80% | 100个买入信号中至少80个能成交 (排除涨停/停牌/资金不足) |
| **IC衰减检测** | 近2月IC ≥ 研究期70% | 因子alpha未出现不可逆衰减 |
| **夏普比率** | > 0.8 (年化) | 策略的总风险调整收益 |
| **月胜率** | > 55% | 月度收益为正的月份占比 |

### 加分项 (非必须)

| 条件 | 说明 |
|------|------|
| 熊市正收益 | 在基准月收益为负的月份中, 策略仍能取得正收益 |
| 低换手率 | 月单边换手 < 50%，说明不是高频交易/过度优化 |
| 行业分散 | 最大行业集中度 < 40%，避免行业beta伪装alpha |
| 流动性健康 | 持仓中无日均成交额 < 5000万的标的 |

## 毕业流程

### Step 1: 自我评估
运行以下脚本获取当前指标:
```bash
python scripts/export_equity_curve.py --benchmark 000300
python scripts/run_ic_monitor.py
python scripts/init_paper_account.py --status
```

### Step 2: 填报评审表
填写 `data/graduation_checklist.json`:
```json
{
  "paper_start_date": "2026-08-03",
  "evaluation_date": "2026-11-03",
  "metrics": {
    "running_months": 3,
    "annual_excess_return_pct": 8.5,
    "information_ratio": 0.65,
    "max_drawdown_pct": -9.2,
    "buy_fill_rate": 0.87,
    "ic_decay_ratio": 0.82,
    "annual_sharpe": 1.05,
    "monthly_win_rate": 0.67
  },
  "all_conditions_met": true,
  "reviewer_notes": "待人工复查"
}
```

### Step 3: 人工复查
- [ ] 回测曲线 vs 模拟盘曲线一致性检查
- [ ] 因子IC趋势图: 确认无结构性衰减
- [ ] 交易记录抽查: 确认无误成交/异常收费
- [ ] 极端日期检查: 大跌日策略表现是否与回测一致

### Step 4: 实盘授权
全部通过后 → Git tag `live-v1.0-YYYYMMDD` → 小资金实盘启动(建议初始 ≤ 模拟盘资金的20%)

## 降级/暂停条件

以下任一触发 → 暂停实盘/模拟盘, 人工复查:

| 条件 | 阈值 |
|------|------|
| 连续回撤 | 从最高点回撤 > 15% |
| IC结构性衰减 | 连续4周IC < 研究期50% |
| 信号实现率暴跌 | 连续2周 < 50% |
| 净值异常跳变 | 单日 > 5% (非市场原因) |

降级后的处理:
1. 暂停所有买入
2. 人工复查 alpha 因子是否失效
3. 如确认失效 → 下架策略, 进入研发迭代
4. 如为市场环境原因 → 等待恢复后重新评估

## 配置版本管理

模拟盘运行期间:
- Config 必须 git tag 锁死 (`paper-v{M}.{N}-{YYYYMMDD}`)
- 任何 config 变更必须在 `storage.config` 中记录 (`config_changed_at`, `config_changed_hash`)
- 变更后需重新评估 (不是重新计时)
- 实盘前最后一个月不允许任何 config 变更

## 经验教训记录

### 常见假alpha信号

| 信号 | 可能原因 |
|------|----------|
| 模拟盘收益 >> 回测收益 | 前视偏差 (数据泄露) / 生存偏差 / 未来函数 |
| 某个行业持续贡献 > 50%收益 | 行业beta, 非alpha |
| 少数股票贡献 > 80%收益 | 过度集中, 不可持续 |
| 模拟盘收益 << 回测收益 | 交易成本低估 / 滑点模型不准 / 流动性问题 |
| IC突然翻正 | 检查是否切换了数据源/因子定义 |

### 模拟盘 checklist

- [ ] 每天收盘后自动运行, 无需人工干预
- [ ] 数据更新+质量校验+信号生成+执行全链路自动化
- [ ] 异常自动告警 (钉钉/微信)
- [ ] 每周 IC 监控自动运行
- [ ] 每月手动复查权益曲线 + 信号实现率
